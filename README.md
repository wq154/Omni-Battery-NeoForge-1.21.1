# Omni Battery · 万能电池

> 一台装得下整片世界的电池。从 10G FE 到**无限容量**，为大型整合包与自动化基地而生。

**作者**：Ayaka　·　**Mod ID**：`omnibattery`　·　**版本**：1.0.0

## 支持版本

| Minecraft | 加载器 | 说明 |
|-----------|--------|------|
| **1.21.1** | NeoForge `[21.1,)` | 本仓库（移植版，功能 1:1 对齐 + 扩展） |
| 1.20.1 | Forge `[47,)` | 见 [Omni-Battery](https://github.com/wq154/Omni-Battery) |

## 特性

### 五级电池
| 等级 | 容量 | 速率档位（FE/t） |
|------|------|------------------|
| 低级 | 10 G | 100K → 5M |
| 中级 | 100 G | 500K → 10M |
| 高级 | 1 T | 1M → 25M |
| 精英 | 100 T | 2.5M → 50M |
| **终极** | **∞（Long.MAX_VALUE）** | 50M → 100M → 250M → 500M → **无限** |

### 核心能力
- **无限档突破**：终极电池最高速率档可突破 Forge 能量 API 的 21 亿 int 上限（内部 long 存储 + int 分块循环传输，单 tick 可搬运远超 21 亿 FE）
- **吸电 / 供电独立**：两个方向各自按设定速率工作，互不挤占，GUI 中分行实时显示
- **实时趋势图**：GUI 底部显示最近 60 秒的吸电（橙）/ 供电（青）折线

### 视觉
- **立体 3D 模型**：顶盖 + 主体 + 底盘，五色金属区分（铁 / 铜 / 银 / 金 / 钛紫）
- **玻璃观察窗**：电量柱随充放电实时变化（方块状态 0-10 档）
- **方块表面实时数值**：
  - 普通电池 → 百分比（`0%` 黑 · `1-25%` 红 · `26-50%` 黄 · `51-100%` 蓝；充电中绿色 + ⚡）
  - 终极电池 → 电量简写（如 `2.15B FE`）

### 交互
- **中文 GUI**：圆形能量表 + 完整数值（千分位，不用 K/M/B/T 缩写）、模式 / 速率 / 范围切换、实时吸电供电、趋势图
- **机器贴纸**：`供电` / `吸电` / `过载` / `清除` 四模式；过载模式可绕过常规 API 限制（反射 / NBT 直读写）
- **自动贴标**：左键空气切换，放置机器时自动贴上当前模式的标签
- **范围显示**：可视化显示工作半径

### 可选集成
- **Jade**：Tooltip 显示真实 long 容量（不再卡在 2.14G）
- **Curios**：贴纸可放入饰品栏 CHARM 槽

## 构建

需要 **JDK 21**。

```bash
# Windows
gradlew.bat build

# Linux / macOS
./gradlew build
```

产物：`build/libs/omni-battery-neoforge-1.21.1-1.0.0-neoforge.1.21.1.jar`

> 仓库自带的 Gradle Wrapper 无需额外安装 Gradle。

## 安装

1. 安装 Minecraft 1.21.1 + NeoForge 21.1+
2. 将构建产物（或 [Releases](../../releases) 中的 jar）放入 `.minecraft/mods/`
3. 可选：同时安装 Jade / Curios 以获得集成功能
